requests that is run time data), EEPROM flash(car model)PIN CONCEPTS:only 3.3 Volt dont direct 12v or 5V from vehicle---MCP2515 it is a CAN controller used to talk using binary codes and to talk with mcp SPI is usedin SPI 1st keep the CS low whenever performing any actions and turn it high only when the task is completethe same line is used for both writing and readingthe format is reset ,read , write here reset is used to clear the previous records or datawhenever writing code for spi start with begin transaction and after complete call end transactionSPI.Transfer() is used to send any info like data , reg address or commandsSPI.beginTransaction(SPISettings(10000000, MSBFIRST, SPI_MODE0)); common for all beginresult = SPI.transfer(0x00); // clock and read back data → Vehicle speed sensorP0200 → Injector circuitP0350 → Ignition coilCOMMAND TO GET STORED ERROR CODES : 02 03 00 00 00 00 00 00RESPONSE : 06 43 01 30 01 10 00 00 (MUST BE DECODED  TO GET ERROR CODE)PID:0x0C → RPM0x11 → Throttle position0x05 → Coolant temp0x0B → MAP pressure0x14 → O₂ sensor voltageEXECUTION :SENT DATA : 02 01 0C 00 00 00 00 00here,02 => data length 01 => data type (here it means live data )0C => PID the id of required data (0c is for RPM)All the other 00 are padding to match the 8 byte of CANRECIEVED DATA : 04 41 0C A B 00 00 00 04  =>  Data length 41  =>  41 = 0x40 + service number(01) given response is positive 0C  =>  PID confirmation A,B =>  Raw data of RPM (RPM = ((A * 256) + B) / 4)common for all bikes remaining padding🔹 Case 1: Throttle position (PID 0x11)   =>  Throttle %       = (A * 100) / 255🔹 Case 2: Intake air temp   (PID 0x0F)   =>  Temperature (°C) = A - 40🔹 Case 3: MAP sensor        (PID 0x0B)   =>  MAP (kPa)        = A🔹 Case 4: O₂ sensor voltage (PID 0x14)   =>  Voltage          = A / 200🔹 Case 5: RPM               (PID 0x0C)   =>  RPM              = ((A * 256) + B) / 4)FORMULA:PID 0x0F → (A - 40)PID 0x11 → (A * 100) / 255PID 0x14 → (A / 200)PID 0x05 → (A - 40)PID 0x0B →  APID 0x0C → (A * 256) + B) / 4ERROR CODES:they are not provided as codes instead given as numbers which are decoded just like the live dataRECIEVED DATA :06 43 01 30 01 10 00 00Here06 is length43 is error codes indication0 error type1 30 is error code therefore the error code is [P0130]0 error type1 10 is error code therefore the error code is [P0110]TABLE:| First nibble | Letter         || ------------ | -------------- || 0            | P (Powertrain) || 1            | C (Chassis)    || 2            | B (Body)       || 3            | U (Network)    |ERROR CODES :P0130-P0135 => O2 SENSORP0171/P0172 => FUELE TRIM OUT OF RANGE (CHECK FOR VACCUM TUBES,PETROL PUMP)P0420       => CATALYST CONVERTER (CHECK TEMPERATURE , O2 SENSOR LEADS , EXHAUST LEAKS)P0100-P0104 => MAF/MAP SENSOR CIRCUIT (CHECK SENOR VOLTAGE , THROTTLE BODY )P0110-P0115 => IAT/ECT SENSOR(CEHCK COOLANT TEMPERATURE SENSOR,AIR INTAKE FILTER)P0200-P0204 => INJECTOR FAULTP0210       => INJECTOR/FUEL PUMPP0300-P0304 => ENGINE MISFIREP0350-P0360 => IGNITION COIL(CHECK ALL COIL SELF,POWER)P0400       => EGR FLOW(CHECK EGR VALVES)U0100/U0121 => CAN BUS COMMUNICATION LOST (ECU CANNOT CONNECT WITH OTHER MODULE)
